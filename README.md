# 💫 Mi Primer viaje  - Tu Asistente de Planificación de Viajes:
Una aplicación completa para planificar viajes construida con React y Vite, que cuenta con múltiples herramientas para ayudarte a planificar tu viaje de manera efectiva. Desde la gestión de tareas hasta la planificación de rutas, verificación del clima y cálculos de costos de combustible, RoadTrip proporciona todo lo que necesitas para un viaje bien organizado.

# 📊 Características Principales:

# Gestor de Tareas

Tablero Kanban intuitivo con funcionalidad de arrastrar y soltar
Diseño responsivo para todos los dispositivos
Actualizaciones de estado de tareas en tiempo real
Optimizado para dispositivos móviles

# Planificación de Ruta

Mapa interactivo desarrollado con React Leaflet
Cálculo de ruta con estimación de distancia
Visualización del recorrido entre punto de inicio y final
Búsqueda de ubicaciones fácil de usar

# Pronóstico del Tiempo

Datos meteorológicos en tiempo real a través de la API de OpenWeatherMap
Condiciones climáticas a lo largo de tu ruta
Pronósticos de temperatura y precipitaciones
Ayuda a planificar según las condiciones climáticas

# Calculadora de Costos de Combustible

Estima los costos de combustible para tu viaje
Ingresa el consumo de combustible de tu vehículo
Calcula los gastos totales del viaje
Ayuda a presupuestar tus costos de viaje

# Tecnologías

React + Vite
@dnd-kit para arrastrar y soltar
React Leaflet para mapas
API de OpenWeatherMap
Tailwind CSS
JavaScript Moderno
